## About

This repository gathers the notebooks produced during studies and courses, kept together as a reference archive. Each notebook is self-contained and can be opened directly in Google Colab — no local setup required.

## How to use

Click the **Open in Colab** badge at the top of any notebook, or open it directly on GitHub — the notebooks render in the browser.

```bash
git clone https://github.com/vitoriaayres/NOTEBOOKS_COMPILADOS.git
cd NOTEBOOKS_COMPILADOS
jupyter notebook
```
